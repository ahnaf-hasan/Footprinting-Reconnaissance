### 🎯 Footprinting

### 📌 What is Footprinting?

Footprinting is the process of collecting information about a target organization, network, or system before performing a security assessment.

It helps security professionals understand the target's digital presence, infrastructure, and publicly available information.

---

### 🌐 Types of Footprinting

- Passive Footprinting
- Active Footprinting

---

### 📋 Information Gathering

- Domain Information
- IP Addresses
- DNS Records
- Subdomains
- Email Addresses
- Organization Details
- Public Network Information
- Technology Information

---

### 🛡️ Prevention

- Protect sensitive public information.
- Secure domain and DNS configurations.
- Limit unnecessary information exposure.
- Monitor publicly exposed assets.
- Regularly review digital footprints.

---

### 🔎 Reconnaissance


### 📌 What is Reconnaissance?

Reconnaissance is the information-gathering phase of ethical hacking and penetration testing.

It involves collecting information about a target to understand its infrastructure, technologies, and potential attack surface.

---

### 🌐 Types of Reconnaissance

- Passive Reconnaissance
- Active Reconnaissance

---


### 📋 Information Gathering

- Domain Information
- IP Addresses
- Open Ports
- Subdomains
- Running Services
- Operating System Information
- Web Technologies
- Network Infrastructure

---

### 🛡️ Prevention

- Monitor externally exposed assets.
- Secure unnecessary public services.
- Configure firewalls properly.
- Regularly audit network infrastructure.
- Keep systems and services updated.

---
